## 今回お願いする確認（GU-01／GU-04）

従来動作した実媒体を使う。まず普段のゲーム一つで確認し、追加形式は手元にあるものだけでよい。
表示が合うだけでなく、ゲームが実際に読み込み・起動・続行できることを確認する。

| 操作 | 期待 |
|---|---|
| ゲーム中にDrive 1だけ、Drive 2だけをメニューから交換 | 指定Driveだけ変わり、他Driveを維持。意図しないresetなし。ゲームが続行する |
| Eject→再挿入、multi-bankのbank切替 | 通常どおり使える。任意bankを一つ確認し、bank 0/1に限定されない |
| 別D88二枚の二Drive指定、または二行M3U | 指定したDrive／bankの両方が使える |
| raw multi-bank D88をD&D | bank 0/1で起動し、resetを伴う |
| 単一bank D88または一行M3UをD&D | Drive 1に指定媒体、Drive 2は空。resetを伴う |
| 二行M3UをD&D | 両Driveの指定構成でreset後に起動する |

メニュー操作はmouseとkeyboardを少なくとも一回ずつ確認する。
D&Dは必ずresetする。自動試験では一回を数えているので、実働では不自然な二重bootや読み込み不能がないかを見る。

CLIを普段使う場合は、XM8を終了してから、下のパスを実媒体へ置き換えて一回確認する。

```sh
/Users/seiji/dev/_Emu/xm8mac/build-ra/xm8.app/Contents/MacOS/xm8 "/実際の場所/起動.d88#0" "/実際の場所/データ.d88#0"
```

今回の依頼はRA OFFに絞る。RA ONの全項目、実回線の切断、故障注入をやり直す必要はない。
