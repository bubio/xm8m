# 入力処理の自動テスト

`input_test` は実際の `Input`、`SoftKey`、`Setting` を使用します。
描画、Appのコンポーネント取得、VMへの通知・出力だけをテスト用の実装に置き換え、
ROM、ユーザー設定、ウィンドウ、実ジョイスティックを使用しません。

確認項目:

- キーの押下・解放・同時押し・リピート・未割り当てキー。
- 左右Shiftの独立した出力、物理キーとソフトキーの重なり、ソフトShiftのラッチ。
- フォーカス喪失時のキー・キャッシュ・ジョイスティック・遅延解放状態の解除。
- フォーカス復帰後の再入力と、古いソフトキー解放が新しい押下を解除しないこと。
- 初期化時のカーソル4方向・数字10キーの割り当て、割り当ての無効化、押下中の変更。
- 同じVMキーへの複数入力、ジョイスティックのキー割り当て変更中の解放。
- Inputのマッピング表より大きいSDL scancodeの無視。

遅延解放はテスト用friendから経過時刻・待機状態だけを設定し、実際の解除処理を実行します。
実時間のsleepや描画タイミングには依存しません。実際のSDLイベント配送、OSのフォーカス通知、
実機のキー配列・IME・ゲームパッドの確認は、この自動テストには含みません。

```sh
scripts/verify_ra.sh --scope ui
```

CTestの全テストにも登録されるため、既存のmacOS・Windows x64・Linux CIで自動実行されます。
